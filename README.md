# Clinic Management System

A C++ console-based Clinic Management System using OOP, Data Structures, and Algorithms.

## Features

- Patient and Doctor Management
- Custom Priority Queue for the Waiting Room
- Custom Linked List for Visit History
- Emergency and Normal Visits
- Binary Search
- Selection Sort
- Recursion
- Runtime Polymorphism
- Operator Overloading

## Data Structures

- Custom Priority Queue
- Custom Singly Linked List

## Algorithms

- Binary Search: O(log n)
- Selection Sort: O(n²)
- Recursive Total Calculation: O(v)

## Compile & Run

```bash
g++ src/*.cpp -Iinclude -o clinic
./clinic
```
